## Objective
To configure Visual Studio Code for C and C++ programming using the GCC compiler.

## Tools Used
- Visual Studio Code
- C/C++ Extension by Microsoft
- MSYS2
- MinGW-w64 GCC Compiler

## Execution Steps
1. Installed Visual Studio Code.
2. Installed the C/C++ extension.
3. Installed MSYS2 and the GCC compiler.
4. Added the GCC `bin` folder to the Windows PATH.
5. Verified the installation using:
   `gcc --version`
   `g++ --version`
6. Created a C program named `hello.c`.
7. Compiled the program using:
   `gcc hello.c -o hello.exe`
8. Executed the program using:
   `.\hello.exe`
9. Verified the output:
   `Hello, World!`

## Result
The C/C++ development environment was successfully configured, and the Hello World program compiled and executed successfully.
